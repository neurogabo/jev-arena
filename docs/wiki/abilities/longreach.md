# Long Reach

`ability:longreach` · This Pokemon's attacks do not make contact with the target.

## Definition

This Pokemon's attacks do not make contact with the target.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
