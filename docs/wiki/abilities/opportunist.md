# Opportunist

`ability:opportunist` · When an opposing Pokemon has a stat stage raised, this Pokemon copies the effect.

## Definition

When an opposing Pokemon has a stat stage raised, this Pokemon copies the effect.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
