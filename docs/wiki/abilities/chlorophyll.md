# Chlorophyll

`ability:chlorophyll` · If Sun is active, this Pokemon's Speed is doubled.

## Definition

If Sun is active, this Pokemon's Speed is doubled. This effect is prevented if this Pokemon is holding a Utility Umbrella.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
