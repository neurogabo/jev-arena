# Steadfast

`ability:steadfast` · If this Pokemon flinches, its Speed is raised by 1 stage.

## Definition

If this Pokemon flinches, its Speed is raised by 1 stage.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
