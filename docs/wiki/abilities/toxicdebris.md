# Toxic Debris

`ability:toxicdebris` · If this Pokemon is hit by a physical attack, Toxic Spikes are set on the opposing side.

## Definition

If this Pokemon is hit by a physical attack, Toxic Spikes are set on the opposing side.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
