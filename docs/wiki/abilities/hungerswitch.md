# Hunger Switch

`ability:hungerswitch` · If Morpeko, it changes between Full Belly and Hangry Mode at the end of each turn.

## Definition

If this Pokemon is a Morpeko, it changes formes between its Full Belly Mode and Hangry Mode at the end of each turn.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
