# Moody

`ability:moody` · Boosts a random stat (except accuracy/evasion) +2 and another stat -1 every turn.

## Definition

This Pokemon has a random stat, other than accuracy or evasiveness, raised by 2 stages and another stat lowered by 1 stage at the end of each turn.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
