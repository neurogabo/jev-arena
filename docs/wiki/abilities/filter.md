# Filter

`ability:filter` · This Pokemon receives 3/4 damage from supereffective attacks.

## Definition

This Pokemon receives 3/4 damage from supereffective attacks.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
