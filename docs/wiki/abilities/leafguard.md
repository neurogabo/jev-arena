# Leaf Guard

`ability:leafguard` · If Sun is active, this Pokemon cannot be statused and Rest will fail for it.

## Definition

If Sun is active, this Pokemon cannot become affected by a non-volatile status condition or Yawn, and Rest will fail for it. This effect is prevented if this Pokemon is holding a Utility Umbrella.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
