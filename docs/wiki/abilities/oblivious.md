# Oblivious

`ability:oblivious` · This Pokemon cannot be infatuated or taunted. Immune to Intimidate.

## Definition

This Pokemon cannot be infatuated or taunted. Gaining this Ability while infatuated or taunted cures it. This Pokemon is immune to the effect of the Intimidate Ability.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
