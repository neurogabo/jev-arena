# Multiscale

`ability:multiscale` · If this Pokemon is at full HP, damage taken from attacks is halved.

## Definition

If this Pokemon is at full HP, damage taken from attacks is halved.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
