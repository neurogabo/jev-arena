# Iron Fist

`ability:ironfist` · This Pokemon's punch-based attacks have 1.2× power. Sucker Punch is not boosted.

## Definition

This Pokemon's punch-based attacks have their power multiplied by 1.2.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
