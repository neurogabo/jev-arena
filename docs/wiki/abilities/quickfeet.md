# Quick Feet

`ability:quickfeet` · If this Pokemon is statused, its Speed is 1.5×; ignores Speed drop from paralysis.

## Definition

If this Pokemon has a non-volatile status condition, its Speed is multiplied by 1.5. This Pokemon ignores the paralysis effect of halving Speed.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
