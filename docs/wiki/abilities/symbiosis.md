# Symbiosis

`ability:symbiosis` · If an ally uses its item, this Pokemon gives its item to that ally immediately.

## Definition

If an ally uses its item, this Pokemon gives its item to that ally immediately. Does not activate if the ally's item was stolen or knocked off, or if the ally used an Eject Button or Eject Pack.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
