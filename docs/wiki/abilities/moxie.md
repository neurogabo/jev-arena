# Moxie

`ability:moxie` · This Pokemon's Attack is raised by 1 stage if it attacks and KOes another Pokemon.

## Definition

This Pokemon's Attack is raised by 1 stage if it attacks and knocks out another Pokemon.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
