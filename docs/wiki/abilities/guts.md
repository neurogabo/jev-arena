# Guts

`ability:guts` · If this Pokemon is statused, its Attack is 1.5×; ignores burn halving physical damage.

## Definition

If this Pokemon has a non-volatile status condition, its Attack is multiplied by 1.5. This Pokemon's physical attacks ignore the burn effect of halving damage.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
