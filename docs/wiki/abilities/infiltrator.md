# Infiltrator

`ability:infiltrator` · Moves ignore substitutes and foe's Reflect/Light Screen/Safeguard/Mist/Aurora Veil.

## Definition

This Pokemon's moves ignore substitutes and the opposing side's Reflect, Light Screen, Safeguard, Mist, and Aurora Veil.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
