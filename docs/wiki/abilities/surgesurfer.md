# Surge Surfer

`ability:surgesurfer` · If Electric Terrain is active, this Pokemon's Speed is doubled.

## Definition

If Electric Terrain is active, this Pokemon's Speed is doubled.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
