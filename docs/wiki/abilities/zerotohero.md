# Zero to Hero

`ability:zerotohero` · If this Pokemon is a Palafin in Zero Form, switching out has it change to Hero Form.

## Definition

If this Pokemon is a Palafin in Zero Form, switching out has it change to Hero Form.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
