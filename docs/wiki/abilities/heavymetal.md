# Heavy Metal

`ability:heavymetal` · This Pokemon's weight is doubled.

## Definition

This Pokemon's weight is doubled. This effect is calculated after the effect of Autotomize, and before the effect of Float Stone.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
