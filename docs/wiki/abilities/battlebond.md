# Battle Bond

`ability:battlebond` · After KOing a Pokemon: raises Attack, Sp. Atk, Speed by 1 stage. Once per battle.

## Definition

If this Pokemon is a Greninja, its Attack, Special Attack, and Speed are raised by 1 stage if it attacks and knocks out another Pokemon. This effect can only happen once per battle.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
