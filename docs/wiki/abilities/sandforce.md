# Sand Force

`ability:sandforce` · This Pokemon's Ground/Rock/Steel attacks do 1.3× in Sandstorm; immunity to it.

## Definition

If Sandstorm is active, this Pokemon's Ground-, Rock-, and Steel-type attacks have their power multiplied by 1.3. This Pokemon takes no damage from Sandstorm.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
