# Shed Skin

`ability:shedskin` · This Pokemon has a 33% chance to have its status cured at the end of each turn.

## Definition

This Pokemon has a 33% chance to have its non-volatile status condition cured at the end of each turn.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
