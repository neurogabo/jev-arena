# Armor Tail

`ability:armortail` · This Pokemon and its allies are protected from opposing priority moves.

## Definition

Priority moves used by opposing Pokemon targeting this Pokemon or its allies are prevented from having an effect.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
