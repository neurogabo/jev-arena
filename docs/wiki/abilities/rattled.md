# Rattled

`ability:rattled` · Speed is raised 1 stage if hit by a Bug-, Dark-, or Ghost-type attack, or Intimidated.

## Definition

This Pokemon's Speed is raised by 1 stage if hit by a Bug-, Dark-, or Ghost-type attack, or if an opposing Pokemon affected this Pokemon with the Intimidate Ability.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
