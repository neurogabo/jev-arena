# Spicy Spray

`ability:spicyspray` · If this Pokemon is hit by an attack, the attacker becomes burned.

## Definition

If this Pokemon is hit by an attack, the attacker becomes burned.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
