# Innards Out

`ability:innardsout` · If this Pokemon is KOed with a move, that move's user loses an equal amount of HP.

## Definition

If this Pokemon is knocked out with a move, that move's user loses HP equal to the amount of damage inflicted on this Pokemon.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
