# Compound Eyes

`ability:compoundeyes` · This Pokemon's moves have their accuracy multiplied by 1.3.

## Definition

This Pokemon's moves have their accuracy multiplied by 1.3.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
