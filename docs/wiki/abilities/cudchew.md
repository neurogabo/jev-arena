# Cud Chew

`ability:cudchew` · If this Pokemon eats a Berry, it will eat that Berry again at the end of the next turn.

## Definition

If this Pokemon eats a Berry, it will eat that Berry again at the end of the next turn.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
