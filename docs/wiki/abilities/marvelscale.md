# Marvel Scale

`ability:marvelscale` · If this Pokemon has a non-volatile status condition, its Defense is multiplied by 1.5.

## Definition

If this Pokemon has a non-volatile status condition, its Defense is multiplied by 1.5.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
