# Friend Guard

`ability:friendguard` · This Pokemon's allies receive 3/4 damage from other Pokemon's attacks.

## Definition

This Pokemon's allies receive 3/4 damage from other Pokemon's attacks.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
