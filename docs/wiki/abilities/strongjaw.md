# Strong Jaw

`ability:strongjaw` · This Pokemon's bite-based attacks have 1.5× power. Bug Bite is not boosted.

## Definition

This Pokemon's bite-based attacks have their power multiplied by 1.5.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
