# No Guard

`ability:noguard` · Every move used by or against this Pokemon will always hit.

## Definition

Every move used by or against this Pokemon will always hit.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
