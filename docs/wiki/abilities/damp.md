# Damp

`ability:damp` · Prevents Explosion/Mind Blown/Misty Explosion/Self-Destruct/Aftermath while active.

## Definition

While this Pokemon is active, Explosion, Mind Blown, Misty Explosion, Self-Destruct, and the Aftermath Ability are prevented from having an effect.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
