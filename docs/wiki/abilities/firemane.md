# Fire Mane

`ability:firemane` · This Pokemon's offensive stat is multiplied by 1.5 while using a Fire-type attack.

## Definition

This Pokemon's offensive stat is multiplied by 1.5 while using a Fire-type attack.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
