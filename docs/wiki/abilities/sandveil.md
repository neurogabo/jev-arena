# Sand Veil

`ability:sandveil` · If Sandstorm is active, this Pokemon's evasiveness is 1.25×; immunity to Sandstorm.

## Definition

If Sandstorm is active, the accuracy of moves used against this Pokemon is multiplied by 0.8. This Pokemon takes no damage from Sandstorm.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
