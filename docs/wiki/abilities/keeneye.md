# Keen Eye

`ability:keeneye` · This Pokemon's accuracy can't be lowered by others; ignores their evasiveness stat.

## Definition

Prevents other Pokemon from lowering this Pokemon's accuracy stat stage. This Pokemon ignores a target's evasiveness stat stage.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
