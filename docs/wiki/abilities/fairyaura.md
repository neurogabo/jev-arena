# Fairy Aura

`ability:fairyaura` · While this Pokemon is active, a Fairy move used by any Pokemon has 1.33× power.

## Definition

While this Pokemon is active, the power of Fairy-type moves used by active Pokemon is multiplied by 1.33.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
