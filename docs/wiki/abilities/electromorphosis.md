# Electromorphosis

`ability:electromorphosis` · This Pokemon gains the Charge effect when it takes a hit from an attack.

## Definition

This Pokemon gains the Charge effect when it takes a hit from an attack.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
