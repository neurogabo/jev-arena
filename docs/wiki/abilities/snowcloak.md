# Snow Cloak

`ability:snowcloak` · If Snow is active, this Pokemon's evasiveness is 1.25×.

## Definition

If Snow is active, the accuracy of moves used against this Pokemon is multiplied by 0.8.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
