# Run Away

`ability:runaway` · Clears ordinary trapping restrictions in Champions.

## Definition

In Champions, this ability clears the holder's trapped and maybe-trapped flags through its trapping hooks, allowing escape from ordinary trapping restrictions. It does not remove every independent action restriction, recharge requirement, or the damage component of a binding move.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
