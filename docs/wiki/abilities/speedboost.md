# Speed Boost

`ability:speedboost` · This Pokemon's Speed is raised 1 stage at the end of each full turn on the field.

## Definition

This Pokemon's Speed is raised by 1 stage at the end of each full turn it has been on the field.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
