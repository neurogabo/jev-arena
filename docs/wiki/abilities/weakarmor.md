# Weak Armor

`ability:weakarmor` · If a physical attack hits this Pokemon, Defense is lowered by 1, Speed is raised by 2.

## Definition

If a physical attack hits this Pokemon, its Defense is lowered by 1 stage and its Speed is raised by 2 stages.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
