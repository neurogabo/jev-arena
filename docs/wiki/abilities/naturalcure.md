# Natural Cure

`ability:naturalcure` · This Pokemon has its non-volatile status condition cured when it switches out.

## Definition

This Pokemon has its non-volatile status condition cured when it switches out.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
