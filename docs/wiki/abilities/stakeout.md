# Stakeout

`ability:stakeout` · This Pokemon's offensive stat is doubled against a target that switched in this turn.

## Definition

This Pokemon's offensive stat is doubled against a target that switched in this turn.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
