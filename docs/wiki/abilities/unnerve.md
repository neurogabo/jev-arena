# Unnerve

`ability:unnerve` · While this Pokemon is active, it prevents opposing Pokemon from using their Berries.

## Definition

While this Pokemon is active, it prevents opposing Pokemon from using their Berries. This Ability activates before hazards and other Abilities take effect.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
