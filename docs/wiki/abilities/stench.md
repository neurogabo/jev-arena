# Stench

`ability:stench` · This Pokemon's attacks without a chance to flinch gain a 10% chance to flinch.

## Definition

This Pokemon's attacks without a chance to make the target flinch gain a 10% chance to make the target flinch.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
