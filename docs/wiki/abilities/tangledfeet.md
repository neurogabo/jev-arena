# Tangled Feet

`ability:tangledfeet` · This Pokemon's evasiveness is doubled as long as it is confused.

## Definition

This Pokemon's evasiveness is doubled as long as it is confused.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
