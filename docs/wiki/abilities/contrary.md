# Contrary

`ability:contrary` · If this Pokemon has a stat stage raised it is lowered instead, and vice versa.

## Definition

If this Pokemon has a stat stage raised it is lowered instead, and vice versa.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
