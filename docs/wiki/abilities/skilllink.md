# Skill Link

`ability:skilllink` · This Pokemon's multi-hit attacks always hit the maximum number of times.

## Definition

This Pokemon's multi-hit attacks always hit the maximum number of times. Triple Kick and Triple Axel do not check accuracy for the second and third hits.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
