# Stall

`ability:stall` · This Pokemon moves last among Pokemon using the same or greater priority moves.

## Definition

This Pokemon moves last among Pokemon using the same or greater priority moves.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
