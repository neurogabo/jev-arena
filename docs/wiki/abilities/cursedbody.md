# Cursed Body

`ability:cursedbody` · If this Pokemon is hit by an attack, there is a 30% chance that move gets disabled.

## Definition

If this Pokemon is hit by an attack, there is a 30% chance that move gets disabled unless one of the attacker's moves is already disabled.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
