# Sand Spit

`ability:sandspit` · When this Pokemon is hit by an attack, the effect of Sandstorm begins.

## Definition

When this Pokemon is hit by an attack, the effect of Sandstorm begins.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
