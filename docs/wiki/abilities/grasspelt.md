# Grass Pelt

`ability:grasspelt` · If Grassy Terrain is active, this Pokemon's Defense is multiplied by 1.5.

## Definition

If Grassy Terrain is active, this Pokemon's Defense is multiplied by 1.5.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
