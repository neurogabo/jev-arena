# Soundproof

`ability:soundproof` · This Pokemon is immune to sound-based moves, unless it used the move.

## Definition

This Pokemon is immune to sound-based moves, unless it used the move.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
