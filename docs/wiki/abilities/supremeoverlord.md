# Supreme Overlord

`ability:supremeoverlord` · This Pokemon's moves have 10% more power for each fainted ally, up to 5 allies.

## Definition

This Pokemon's moves have their power multiplied by 1+(X × 0.1), where X is the total number of times any Pokemon has fainted on the user's side when this Ability became active, and X cannot be greater than 5.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
