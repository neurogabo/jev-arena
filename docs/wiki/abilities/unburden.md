# Unburden

`ability:unburden` · Speed is doubled on held item loss; boost is lost if it switches, gets new item/Ability.

## Definition

If this Pokemon loses its held item for any reason, its Speed is doubled as long as it remains active, has this Ability, and is not holding an item.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
