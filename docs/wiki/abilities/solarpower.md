# Solar Power

`ability:solarpower` · If Sun is active, this Pokemon's Sp. Atk is 1.5×; loses 1/8 max HP per turn.

## Definition

If Sun is active, this Pokemon's Special Attack is multiplied by 1.5 and it loses 1/8 of its maximum HP, rounded down, at the end of each turn. These effects are prevented if the Pokemon is holding a Utility Umbrella.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
