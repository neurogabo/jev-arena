# Slush Rush

`ability:slushrush` · If Snow is active, this Pokemon's Speed is doubled.

## Definition

If Snow is active, this Pokemon's Speed is doubled.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
