# Rivalry

`ability:rivalry` · This Pokemon's attacks do 1.25× on same gender targets; 0.75× on opposite gender.

## Definition

This Pokemon's attacks have their power multiplied by 1.25 against targets of the same gender or multiplied by 0.75 against targets of the opposite gender. There is no modifier if either this Pokemon or the target is genderless.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
