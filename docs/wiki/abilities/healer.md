# Healer

`ability:healer` · 50% chance this Pokemon's ally has its status cured at the end of each turn.

## Definition

50% chance this Pokemon's ally has its non-volatile status condition cured at the end of each turn.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
