# Synchronize

`ability:synchronize` · If another Pokemon burns/poisons/paralyzes this Pokemon, it also gets that status.

## Definition

If another Pokemon burns, paralyzes, poisons, or badly poisons this Pokemon, that Pokemon receives the same non-volatile status condition.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
