# Big Pecks

`ability:bigpecks` · Prevents other Pokemon from lowering this Pokemon's Defense stat stage.

## Definition

Prevents other Pokemon from lowering this Pokemon's Defense stat stage.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
