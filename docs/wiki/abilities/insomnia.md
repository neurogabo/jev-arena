# Insomnia

`ability:insomnia` · This Pokemon cannot fall asleep. Gaining this Ability while asleep cures it.

## Definition

This Pokemon cannot fall asleep. Gaining this Ability while asleep cures it.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
