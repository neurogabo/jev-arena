# Imposter

`ability:imposter` · On switch-in, this Pokemon Transforms into the opposing Pokemon that is facing it.

## Definition

On switch-in, this Pokemon Transforms into the opposing Pokemon that is facing it. If there is no Pokemon at that position, this Pokemon does not Transform.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
