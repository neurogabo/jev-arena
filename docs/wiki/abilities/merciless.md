# Merciless

`ability:merciless` · This Pokemon's attacks are critical hits if the target is poisoned.

## Definition

This Pokemon's attacks are critical hits if the target is poisoned.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
