# Mega Launcher

`ability:megalauncher` · This Pokemon's pulse moves have 1.5× power. Heal Pulse heals 3/4 target's max HP.

## Definition

This Pokemon's pulse moves have their power multiplied by 1.5. Heal Pulse restores 3/4 of a target's maximum HP, rounded half down.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
