# Liquid Ooze

`ability:liquidooze` · This Pokemon damages those draining HP from it for as much as they would heal.

## Definition

This Pokemon damages those draining HP from it for as much as they would heal.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
