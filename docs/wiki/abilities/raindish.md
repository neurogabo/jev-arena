# Rain Dish

`ability:raindish` · If Rain is active, this Pokemon heals 1/16 of its max HP each turn.

## Definition

If Rain is active, this Pokemon restores 1/16 of its maximum HP, rounded down, at the end of each turn. This effect is prevented if this Pokemon is holding a Utility Umbrella.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
