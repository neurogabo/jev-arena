# Analytic

`ability:analytic` · This Pokemon's attacks have 1.3× power if it is the last to move in a turn.

## Definition

The power of this Pokemon's move is multiplied by 1.3 if it is the last to move in a turn. Does not affect Doom Desire and Future Sight.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
