# Harvest

`ability:harvest` · If last item used is a Berry, 50% chance to restore it each end of turn. 100% in Sun.

## Definition

If the last item this Pokemon used is a Berry, there is a 50% chance it gets restored at the end of each turn. If Sun is active, this chance is 100%.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
