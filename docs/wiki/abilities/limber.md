# Limber

`ability:limber` · This Pokemon cannot be paralyzed. Gaining this Ability while paralyzed cures it.

## Definition

This Pokemon cannot be paralyzed. Gaining this Ability while paralyzed cures it.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
