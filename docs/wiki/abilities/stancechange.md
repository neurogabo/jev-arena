# Stance Change

`ability:stancechange` · If Aegislash, changes Forme to Blade before attacks and Shield before King's Shield.

## Definition

If this Pokemon is an Aegislash, it changes to Blade Forme before using an attacking move, and changes to Shield Forme before using King's Shield.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
