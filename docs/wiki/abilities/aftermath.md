# Aftermath

`ability:aftermath` · If this Pokemon is KOed with a contact move, that move's user loses 1/4 its max HP.

## Definition

If this Pokemon is knocked out with a contact move, that move's user loses 1/4 of its maximum HP, rounded down. This effect is prevented if the move's user has the Magic Guard Ability or if any active Pokemon has the Damp Ability.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
