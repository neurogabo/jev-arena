# Hydration

`ability:hydration` · This Pokemon has its status cured at the end of each turn if Rain is active.

## Definition

This Pokemon has its non-volatile status condition cured at the end of each turn if Rain is active. This effect is prevented if this Pokemon is holding a Utility Umbrella.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
