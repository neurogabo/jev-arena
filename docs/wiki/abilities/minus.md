# Minus

`ability:minus` · If an active ally has this Ability or the Plus Ability, this Pokemon's Sp. Atk is 1.5×.

## Definition

If an active ally has this Ability or the Plus Ability, this Pokemon's Special Attack is multiplied by 1.5.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
