# Ice Body

`ability:icebody` · If Snow is active, this Pokemon heals 1/16 of its max HP each turn.

## Definition

If Snow is active, this Pokemon restores 1/16 of its maximum HP, rounded down, at the end of each turn.

Apply this to the holder’s **current** ability. Its starting ability, Mega ability, copied ability, and suppression state can differ.
