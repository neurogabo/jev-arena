# White Herb

`item:whiteherb` · Restores all lowered stat stages to 0 when one is less than 0. Single use.

## Definition

Restores all lowered stat stages to 0 when one is less than 0. Single use.

Apply the effect only while its holder/item state satisfies the rule. Revealed, consumed, removed, exchanged, and suppressed are different states.
