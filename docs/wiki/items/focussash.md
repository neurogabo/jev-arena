# Focus Sash

`item:focussash` · If holder's HP is full, will survive an attack that would KO it with 1 HP. Single use.

## Definition

If holder's HP is full, will survive an attack that would KO it with 1 HP. Single use.

Apply the effect only while its holder/item state satisfies the rule. Revealed, consumed, removed, exchanged, and suppressed are different states.
