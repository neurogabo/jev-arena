# Red Card

`item:redcard` · If holder survives a hit, attacker is forced to switch to a random ally. Single use.

## Definition

If holder survives a hit, attacker is forced to switch to a random ally. Single use.

Apply the effect only while its holder/item state satisfies the rule. Revealed, consumed, removed, exchanged, and suppressed are different states.
