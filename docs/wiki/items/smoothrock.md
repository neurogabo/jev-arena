# Smooth Rock

`item:smoothrock` · Holder's use of Sandstorm lasts 8 turns instead of 5.

## Definition

Holder's use of Sandstorm lasts 8 turns instead of 5.

Apply the effect only while its holder/item state satisfies the rule. Revealed, consumed, removed, exchanged, and suppressed are different states.
