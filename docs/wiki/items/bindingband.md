# Binding Band

`item:bindingband` · Holder's partial-trapping moves deal 1/6 max HP per turn instead of 1/8.

## Definition

Holder's partial-trapping moves deal 1/6 max HP per turn instead of 1/8.

Apply the effect only while its holder/item state satisfies the rule. Revealed, consumed, removed, exchanged, and suppressed are different states.
