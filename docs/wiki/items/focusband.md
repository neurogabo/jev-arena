# Focus Band

`item:focusband` · Holder has a 10% chance to survive an attack that would KO it with 1 HP.

## Definition

Holder has a 10% chance to survive an attack that would KO it with 1 HP.

Apply the effect only while its holder/item state satisfies the rule. Revealed, consumed, removed, exchanged, and suppressed are different states.
