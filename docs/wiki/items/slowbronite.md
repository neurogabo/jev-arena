# Slowbronite

`item:slowbronite` · If held by a Slowbro (not Galarian Slowbro), this item allows it to Mega Evolve.

## Definition

If held by a Slowbro (not Galarian Slowbro), this item allows it to Mega Evolve.

Apply the effect only while its holder/item state satisfies the rule. Revealed, consumed, removed, exchanged, and suppressed are different states.

Mega transformation: Slowbro → Slowbro-Mega. This item does not establish that Mega Evolution has already occurred.
