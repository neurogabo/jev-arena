# Iron Ball

`item:ironball` · Holder is grounded, Speed halved. If Flying type, takes neutral Ground damage.

## Definition

Holder is grounded, Speed halved. If Flying type, takes neutral Ground damage.

Apply the effect only while its holder/item state satisfies the rule. Revealed, consumed, removed, exchanged, and suppressed are different states.
