# Choice Scarf

`item:choicescarf` · Holder's Speed is 1.5×, but it can only select the first move it executes.

## Definition

Holder's Speed is 1.5×, but it can only select the first move it executes.

Apply the effect only while its holder/item state satisfies the rule. Revealed, consumed, removed, exchanged, and suppressed are different states.
