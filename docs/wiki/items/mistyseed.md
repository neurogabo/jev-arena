# Misty Seed

`item:mistyseed` · If the terrain is Misty Terrain, raises holder's Sp. Def by 1 stage. Single use.

## Definition

If the terrain is Misty Terrain, raises holder's Sp. Def by 1 stage. Single use.

Apply the effect only while its holder/item state satisfies the rule. Revealed, consumed, removed, exchanged, and suppressed are different states.
