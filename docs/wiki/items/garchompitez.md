# Garchompite Z

`item:garchompitez` · If held by a Garchomp, this item allows it to Mega Evolve into Mega Garchomp Z.

## Definition

If held by a Garchomp, this item allows it to Mega Evolve into Mega Garchomp Z.

Apply the effect only while its holder/item state satisfies the rule. Revealed, consumed, removed, exchanged, and suppressed are different states.

Mega transformation: Garchomp → Garchomp-Mega-Z. This item does not establish that Mega Evolution has already occurred.
