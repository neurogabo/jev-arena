# Pidgeotite

`item:pidgeotite` · If held by a Pidgeot, this item allows it to Mega Evolve in battle.

## Definition

If held by a Pidgeot, this item allows it to Mega Evolve in battle.

Apply the effect only while its holder/item state satisfies the rule. Revealed, consumed, removed, exchanged, and suppressed are different states.

Mega transformation: Pidgeot → Pidgeot-Mega. This item does not establish that Mega Evolution has already occurred.
