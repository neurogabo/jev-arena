# Dark typing and Prankster

`interaction:dark-prankster` · A Dark target can reject a Prankster-boosted opposing move.

## When to retrieve

An opposing Prankster user may aim a status move at a Dark-type Pokémon.

## Conditional rule

Dark types are immune to opposing moves boosted by Prankster. This is a separate check from ordinary type effectiveness and Psychic Terrain.

## Exceptions and required state

A move affecting the field or the user’s own side is not thereby an attack aimed at the Dark Pokémon. Ally targeting is exempt from this immunity. Check current typing and whether the ability actually modified this move.
