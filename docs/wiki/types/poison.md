# Poison type

`type:poison` · Single-type offensive and defensive matchups; combine with current types and conditional immunities.

## Standard single-type matchups

| Opposing type | Damage received from this type | Damage dealt to this type |
| --- | ---: | ---: |
| Bug | 0.5× | 1× |
| Dark | 1× | 1× |
| Dragon | 1× | 1× |
| Electric | 1× | 1× |
| Fairy | 0.5× | 2× |
| Fighting | 0.5× | 1× |
| Fire | 1× | 1× |
| Flying | 1× | 1× |
| Ghost | 1× | 0.5× |
| Grass | 0.5× | 2× |
| Ground | 2× | 0.5× |
| Ice | 1× | 1× |
| Normal | 1× | 1× |
| Poison | 0.5× | 0.5× |
| Psychic | 2× | 1× |
| Rock | 1× | 0.5× |
| Steel | 1× | 0× |
| Water | 1× | 1× |

For dual types multiply the two applicable defensive factors. Use current types, not merely the species’ starting types. These are ordinary type-chart factors before abilities, grounding, move-specific exceptions, or other modifiers. STAB is a separate modifier.

Additional type-data immunity keys: psn, tox. Interpret these with the status rules and exceptions.
