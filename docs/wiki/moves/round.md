# Round

`move:round` · Power doubles if others used Round this turn.

## Definition

If there are other active Pokemon that chose this move for use this turn, those Pokemon take their turn immediately after the user, in Speed order, and this move's power is 120 for each other user.

| Property | Resolved value |
| --- | --- |
| Type | Normal |
| Category | Special |
| Listed base power | 60 |
| Accuracy | 100% before applicable modifiers |
| Base priority | 0 |
| Target | normal — One adjacent Pokémon other than the user; in doubles this can be either opposing slot or the ally, subject to move-specific restrictions. |
| PP in Champions | 16 |
| Flags | bypasssub, metronome, mirror, protect, sound |
