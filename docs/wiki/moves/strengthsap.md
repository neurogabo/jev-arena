# Strength Sap

`move:strengthsap` · User heals HP=target's Atk stat. Lowers Atk by 1.

## Definition

Lowers the target's Attack by 1 stage. The user restores its HP equal to the target's Attack stat calculated with its stat stage before this move was used. If Big Root is held by the user, the HP recovered is 1.3× normal, rounded half down. Fails if the target's Attack stat stage is -6.
