# Stuff Cheeks

`move:stuffcheeks` · Fails unless a Berry is held. User eats Berry, Def +2.

## Definition

Fails if the user is not holding a Berry. The user eats its Berry and raises its Defense by 2 stages. This effect is not prevented by the Klutz or Unnerve Abilities, or the effects of Embargo or Magic Room.
