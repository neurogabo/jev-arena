# Topsy-Turvy

`move:topsyturvy` · Inverts the target's stat stages.

## Definition

The target's positive stat stages become negative and vice versa. Fails if all of the target's stat stages are 0.

| Property | Resolved value |
| --- | --- |
| Type | Dark |
| Category | Status |
| Listed base power | 0 (0 can mean status or an effect-specific damage rule) |
| Accuracy | No ordinary accuracy check |
| Base priority | 0 |
| Target | normal — One adjacent Pokémon other than the user; in doubles this can be either opposing slot or the ally, subject to move-specific restrictions. |
| PP in Champions | 20 |
| Flags | allyanim, metronome, mirror, protect, reflectable |
