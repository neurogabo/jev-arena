# Storm Throw

`move:stormthrow` · Always results in a critical hit.

## Definition

This move is always a critical hit unless the target is under the effect of Lucky Chant or has the Battle Armor or Shell Armor Abilities.

| Property | Resolved value |
| --- | --- |
| Type | Fighting |
| Category | Physical |
| Listed base power | 60 |
| Accuracy | 100% before applicable modifiers |
| Base priority | 0 |
| Target | normal — One adjacent Pokémon other than the user; in doubles this can be either opposing slot or the ally, subject to move-specific restrictions. |
| PP in Champions | 12 |
| Flags | contact, metronome, mirror, protect |

## Additional effect fields

```json
{
  "willCrit": true
}
```
