# Rising Voltage

`move:risingvoltage` · 2× power if target is grounded in Electric Terrain.

## Definition

If the current terrain is Electric Terrain and the target is grounded, this move's power is doubled.

| Property | Resolved value |
| --- | --- |
| Type | Electric |
| Category | Special |
| Listed base power | 70 |
| Accuracy | 100% before applicable modifiers |
| Base priority | 0 |
| Target | normal — One adjacent Pokémon other than the user; in doubles this can be either opposing slot or the ally, subject to move-specific restrictions. |
| PP in Champions | 20 |
| Flags | metronome, mirror, protect |
