# Howl

`move:howl` · Raises the user's and ally's Attack by 1.

## Definition

Raises the Attack of the user and all allies 1 stage.

| Property | Resolved value |
| --- | --- |
| Type | Normal |
| Category | Status |
| Listed base power | 0 (0 can mean status or an effect-specific damage rule) |
| Accuracy | No ordinary accuracy check |
| Base priority | 0 |
| Target | allies — The user and its allies as defined by the move. |
| PP in Champions | 20 |
| Flags | bypasssub, metronome, snatch, sound |

## Additional effect fields

```json
{
  "boosts": {
    "atk": 1
  }
}
```
