# Twin Beam

`move:twinbeam` · Hits 2 times in one turn.

## Definition

Hits twice. If the first hit breaks the target's substitute, it will take damage for the second hit.

| Property | Resolved value |
| --- | --- |
| Type | Psychic |
| Category | Special |
| Listed base power | 40 |
| Accuracy | 100% before applicable modifiers |
| Base priority | 0 |
| Target | normal — One adjacent Pokémon other than the user; in doubles this can be either opposing slot or the ally, subject to move-specific restrictions. |
| PP in Champions | 12 |
| Flags | mirror, protect |

## Additional effect fields

```json
{
  "multihit": 2
}
```
