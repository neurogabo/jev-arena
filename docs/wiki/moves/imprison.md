# Imprison

`move:imprison` · No foe can use any move known by the user.

## Definition

The user prevents all opposing Pokemon from using any moves that the user also knows as long as the user remains active.

| Property | Resolved value |
| --- | --- |
| Type | Psychic |
| Category | Status |
| Listed base power | 0 (0 can mean status or an effect-specific damage rule) |
| Accuracy | No ordinary accuracy check |
| Base priority | 0 |
| Target | self — The user. |
| PP in Champions | 12 |
| Flags | bypasssub, metronome, mustpressure, snatch |

## Additional effect fields

```json
{
  "volatileStatus": "imprison"
}
```
