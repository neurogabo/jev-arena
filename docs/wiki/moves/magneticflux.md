# Magnetic Flux

`move:magneticflux` · Raises Def, Sp. Def of allies with Plus/Minus by 1.

## Definition

Raises the Defense and Special Defense of Pokemon on the user's side with the Plus or Minus Abilities by 1 stage.

| Property | Resolved value |
| --- | --- |
| Type | Electric |
| Category | Status |
| Listed base power | 0 (0 can mean status or an effect-specific damage rule) |
| Accuracy | No ordinary accuracy check |
| Base priority | 0 |
| Target | allySide — The user’s side of the field. |
| PP in Champions | 20 |
| Flags | bypasssub, distance, metronome, snatch |
