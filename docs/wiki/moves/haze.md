# Haze

`move:haze` · Eliminates all stat changes.

## Definition

Resets the stat stages of all active Pokemon to 0.

| Property | Resolved value |
| --- | --- |
| Type | Ice |
| Category | Status |
| Listed base power | 0 (0 can mean status or an effect-specific damage rule) |
| Accuracy | No ordinary accuracy check |
| Base priority | 0 |
| Target | all — The field/all active Pokémon as defined by the effect. |
| PP in Champions | 20 |
| Flags | bypasssub, metronome |
