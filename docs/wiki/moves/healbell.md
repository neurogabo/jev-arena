# Heal Bell

`move:healbell` · Cures the user's party of all status conditions.

## Definition

Every Pokemon in the user's party is cured of its non-volatile status condition. Active Pokemon with the Soundproof Ability are not cured, unless they are the user.

| --- | --- |
| Type | Normal |

| Listed base power | 0 (0 can mean status or an effect-specific damage rule) |
| Accuracy | No ordinary accuracy check |
| Base priority | 0 |
| Target | allyTeam — Consult the move effect. |
| PP in Champions | 8 |
| Flags | bypasssub, distance, metronome, snatch, sound |
