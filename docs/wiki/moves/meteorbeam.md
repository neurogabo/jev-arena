# Meteor Beam

`move:meteorbeam` · Raises user's Sp. Atk by 1 on turn 1. Hits turn 2.

## Definition

This attack charges on the first turn and executes on the second. Raises the user's Special Attack by 1 stage on the first turn. If the user is holding a Power Herb, the move completes in one turn.

| Property | Resolved value |
| --- | --- |
| Type | Rock |
| Category | Special |
| Listed base power | 120 |
| Accuracy | 90% before applicable modifiers |
| Base priority | 0 |
| Target | normal — One adjacent Pokémon other than the user; in doubles this can be either opposing slot or the ally, subject to move-specific restrictions. |
| PP in Champions | 12 |
| Flags | charge, metronome, mirror, protect |
