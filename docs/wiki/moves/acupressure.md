# Acupressure

`move:acupressure` · Raises a random stat of the user or an ally by 2.

## Definition

Raises a random stat by 2 stages as long as the stat is not already at stage 6. The user can choose to use this move on itself or an adjacent ally. Fails if no stat stage can be raised or if used on an ally with a substitute.

| Property | Resolved value |
| --- | --- |
| Type | Normal |
| Category | Status |
| Listed base power | 0 (0 can mean status or an effect-specific damage rule) |
| Accuracy | No ordinary accuracy check |
| Base priority | 0 |
| Target | adjacentAllyOrSelf — The user or its adjacent ally. |
| PP in Champions | 20 |
| Flags | metronome |
