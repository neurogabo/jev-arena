# Beak Blast

`move:beakblast` · Burns on contact with the user before it moves.

## Definition

If the user is hit by a contact move this turn before it can execute this move, the attacker is burned.

| Property | Resolved value |
| --- | --- |
| Type | Flying |
| Category | Physical |
| Listed base power | 120 |
| Accuracy | 100% before applicable modifiers |
| Base priority | -3 |
| Target | normal — One adjacent Pokémon other than the user; in doubles this can be either opposing slot or the ally, subject to move-specific restrictions. |
| PP in Champions | 8 |
| Flags | bullet, failcopycat, failinstruct, failmefirst, noassist, nosleeptalk, protect |
