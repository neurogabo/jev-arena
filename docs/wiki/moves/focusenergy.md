# Focus Energy

`move:focusenergy` · Raises the user's critical hit ratio by 2.

## Definition

Raises the user's chance for a critical hit by 2 stages. Fails if the user already has the effect. Baton Pass can be used to transfer this effect to an ally.

| Property | Resolved value |
| --- | --- |
| Type | Normal |
| Category | Status |
| Listed base power | 0 (0 can mean status or an effect-specific damage rule) |
| Accuracy | No ordinary accuracy check |
| Base priority | 0 |
| Target | self — The user. |
| PP in Champions | 20 |
| Flags | metronome, snatch |

## Additional effect fields

```json
{
  "volatileStatus": "focusenergy"
}
```
