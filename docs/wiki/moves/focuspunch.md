# Focus Punch

`move:focuspunch` · Fails if the user takes damage before it hits.

## Definition

The user loses its focus and does nothing if it is hit by a damaging attack this turn before it can execute the move.

| Property | Resolved value |
| --- | --- |
| Type | Fighting |
| Category | Physical |
| Listed base power | 150 |
| Accuracy | 100% before applicable modifiers |
| Base priority | -3 |
| Target | normal — One adjacent Pokémon other than the user; in doubles this can be either opposing slot or the ally, subject to move-specific restrictions. |
| PP in Champions | 20 |
| Flags | contact, failcopycat, failinstruct, failmefirst, noassist, nosleeptalk, protect, punch |
