# Burn Up

`move:burnup` · User's Fire type becomes typeless; must be Fire.

## Definition

Fails unless the user is a Fire type. If this move is successful and the user is not Terastallized, the user's Fire type becomes typeless as long as it remains active.

| Property | Resolved value |
| --- | --- |
| Type | Fire |
| Category | Special |
| Listed base power | 130 |
| Accuracy | 100% before applicable modifiers |
| Base priority | 0 |
| Target | normal — One adjacent Pokémon other than the user; in doubles this can be either opposing slot or the ally, subject to move-specific restrictions. |
| PP in Champions | 8 |
| Flags | defrost, metronome, mirror, protect |
