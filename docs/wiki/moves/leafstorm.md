# Leaf Storm

`move:leafstorm` · Lowers the user's Sp. Atk by 2.

## Definition

Lowers the user's Special Attack by 2 stages.

| Property | Resolved value |
| --- | --- |
| Type | Grass |
| Category | Special |
| Listed base power | 130 |
| Accuracy | 90% before applicable modifiers |
| Base priority | 0 |
| Target | normal — One adjacent Pokémon other than the user; in doubles this can be either opposing slot or the ally, subject to move-specific restrictions. |
| PP in Champions | 8 |
| Flags | metronome, mirror, protect |

## Additional effect fields

```json
{
  "self": {
    "boosts": {
      "spa": -2
    }
  }
}
```
