# Air Cutter

`move:aircutter` · High critical hit ratio. Hits adjacent foes.

## Definition

Has a higher chance for a critical hit.

| Property | Resolved value |
| --- | --- |
| Type | Flying |
| Category | Special |
| Listed base power | 60 |
| Accuracy | 95% before applicable modifiers |
| Base priority | 0 |
| Target | allAdjacentFoes — All adjacent opposing Pokémon; spread targeting. |
| PP in Champions | 20 |
| Flags | metronome, mirror, protect, slicing, wind |

## Additional effect fields

```json
{
  "critRatio": 2
}
```
