# Flying Press

`move:flyingpress` · Combines Flying in its type effectiveness.

## Definition

This move combines Flying in its type effectiveness against the target. Damage doubles and no accuracy check is done if the target has used Minimize while active.

| Property | Resolved value |
| --- | --- |
| Type | Fighting |
| Category | Physical |
| Listed base power | 100 |
| Accuracy | 95% before applicable modifiers |
| Base priority | 0 |
| Target | any — One other Pokémon, with move-specific restrictions. |
| PP in Champions | 12 |
| Flags | contact, distance, gravity, metronome, minimize, mirror, nonsky, protect |
