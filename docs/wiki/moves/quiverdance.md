# Quiver Dance

`move:quiverdance` · Raises the user's Sp. Atk, Sp. Def, Speed by 1.

## Definition

Raises the user's Special Attack, Special Defense, and Speed by 1 stage.

| Property | Resolved value |
| --- | --- |
| Type | Bug |
| Category | Status |
| Listed base power | 0 (0 can mean status or an effect-specific damage rule) |
| Accuracy | No ordinary accuracy check |
| Base priority | 0 |
| Target | self — The user. |
| PP in Champions | 20 |
| Flags | dance, metronome, snatch |
