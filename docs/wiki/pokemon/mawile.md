# Mawile

Stat profile favors physical offense; base Speed 50.

## Identity and form

Types: [Steel](../types/steel.md), [Fairy](../types/fairy.md). Weight: 11.5 kg.

Battle forms: [Mawile-Mega](../pokemon/mawilemega.md).

Intrinsic abilities: [Hyper Cutter](../abilities/hypercutter.md), [Intimidate](../abilities/intimidate.md), [Sheer Force](../abilities/sheerforce.md). Use the revealed ability when known.
