# Steelix

Stat profile favors physical offense; base Speed 30.

## Identity and form

Types: [Steel](../types/steel.md), [Ground](../types/ground.md). Weight: 400 kg.

Battle forms: [Steelix-Mega](../pokemon/steelixmega.md).
