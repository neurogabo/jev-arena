# Lucario

Stat profile favors mixed offense; base Speed 90.

## Identity and form

Types: [Fighting](../types/fighting.md), [Steel](../types/steel.md). Weight: 54 kg.

Battle forms: [Lucario-Mega](../pokemon/lucariomega.md), [Lucario-Mega-Z](../pokemon/lucariomegaz.md).

Intrinsic abilities: [Steadfast](../abilities/steadfast.md), [Inner Focus](../abilities/innerfocus.md), [Justified](../abilities/justified.md). Use the revealed ability when known.
