# Salamence-Mega

Intimidate before Mega Evolution; Mega special offense often uses Aerilate Hyper Voice.

## Identity and form

Types: [Dragon](../types/dragon.md), [Flying](../types/flying.md). Weight: 112.6 kg.

Battle form reached from [Salamence](../pokemon/salamence.md). Base stats and intrinsic abilities below describe **Salamence-Mega**.

Transformation item: [Salamencite](../items/salamencite.md).

Intrinsic abilities: [Aerilate](../abilities/aerilate.md). Use the revealed ability when known.
