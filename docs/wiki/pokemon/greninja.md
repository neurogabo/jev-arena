# Greninja

Stat profile favors mixed offense; base Speed 122.

## Identity and form

Types: [Water](../types/water.md), [Dark](../types/dark.md). Weight: 40 kg.

Battle forms: [Greninja-Mega](../pokemon/greninjamega.md).

Intrinsic abilities: [Torrent](../abilities/torrent.md), [Protean](../abilities/protean.md), [Battle Bond](../abilities/battlebond.md). Use the revealed ability when known.
