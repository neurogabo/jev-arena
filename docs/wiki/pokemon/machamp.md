# Machamp

Stat profile favors physical offense; base Speed 55.

## Identity and form

Types: [Fighting](../types/fighting.md). Weight: 130 kg.

Intrinsic abilities: [Guts](../abilities/guts.md), [No Guard](../abilities/noguard.md), [Steadfast](../abilities/steadfast.md). Use the revealed ability when known.
