# Golisopod-Mega

Bulky physical Bug/Steel attacker with Tough Claws; selected builds use setup or priority attacks.

## Identity and form

Types: [Bug](../types/bug.md), [Steel](../types/steel.md). Weight: 148 kg.

Battle form reached from [Golisopod](../pokemon/golisopod.md). Base stats and intrinsic abilities below describe **Golisopod-Mega**.

Transformation item: [Golisopite](../items/golisopite.md).

Intrinsic abilities: [Tough Claws](../abilities/toughclaws.md). Use the revealed ability when known.
