# Excadrill

Stat profile favors physical offense; base Speed 88.

## Identity and form

Types: [Ground](../types/ground.md), [Steel](../types/steel.md). Weight: 40.4 kg.

Battle forms: [Excadrill-Mega](../pokemon/excadrillmega.md).

Intrinsic abilities: [Sand Rush](../abilities/sandrush.md), [Sand Force](../abilities/sandforce.md), [Mold Breaker](../abilities/moldbreaker.md). Use the revealed ability when known.
