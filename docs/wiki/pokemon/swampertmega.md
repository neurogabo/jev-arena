# Swampert-Mega

Stat profile favors physical offense; base Speed 70.

## Identity and form

Types: [Water](../types/water.md), [Ground](../types/ground.md). Weight: 102 kg.

Battle form reached from [Swampert](../pokemon/swampert.md). Base stats and intrinsic abilities below describe **Swampert-Mega**.

Transformation item: [Swampertite](../items/swampertite.md).

Intrinsic abilities: [Swift Swim](../abilities/swiftswim.md). Use the revealed ability when known.
