# Venusaur

Stat profile favors special offense; base Speed 80.

## Identity and form

Types: [Grass](../types/grass.md), [Poison](../types/poison.md). Weight: 100 kg.

Battle forms: [Venusaur-Mega](../pokemon/venusaurmega.md).

Intrinsic abilities: [Overgrow](../abilities/overgrow.md), [Chlorophyll](../abilities/chlorophyll.md). Use the revealed ability when known.
