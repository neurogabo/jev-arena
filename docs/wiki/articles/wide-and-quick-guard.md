# Wide Guard and Quick Guard

Side protection against eligible spread or positive-priority moves, ally interactions, and shared protection counters.

## Reference text

Include when either guard is relevant. Dependencies: priority, target categories, protection bypass, shared protection counter.

Wide Guard has priority +3 and protects the user's side from eligible moves whose target category is all adjacent Pokémon or all adjacent foes. It can protect against an ally's spread move as well as an opponent's. It checks the category even when only one Pokémon is currently in reach. It does not generally block a single-target attack.

Quick Guard has priority +3 and protects the user's side from eligible moves with positive priority, including priority gained from an ability. It can block an eligible move from an ally. Acting early through an item or Speed alone is not equivalent to using a positive-priority move.

These guards do **not** make the ordinary consecutive-use failure roll themselves in this environment, so repeated uses are not subject to Protect's decreasing success chance. They can nevertheless update the shared counter that affects a subsequent personal-protection attempt. Other failure conditions, duplicate side protection, move bypass rules, and action timing still apply.
