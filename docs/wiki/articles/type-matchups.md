# Complete ordinary type matchups

The complete ordinary matchup table for the eighteen types, dual-type multiplication, and explicit exceptions.

## Reference text

Read this table by **attacking move type**. Types in the second column receive 2× damage from that attack type; types in the third receive 0.5×; types in the fourth receive 0×. Every unlisted attacking/defending pair is 1×. This specifies all 324 ordinary matchups among the 18 types.

| Attacking type | 2× against | 0.5× against | 0× against |
| --- | --- | --- | --- |
| Normal | — | Rock, Steel | Ghost |
| Fire | Grass, Ice, Bug, Steel | Fire, Water, Rock, Dragon | — |
| Water | Fire, Ground, Rock | Water, Grass, Dragon | — |
| Electric | Water, Flying | Electric, Grass, Dragon | Ground |
| Grass | Water, Ground, Rock | Fire, Grass, Poison, Flying, Bug, Dragon, Steel | — |
| Ice | Grass, Ground, Flying, Dragon | Fire, Water, Ice, Steel | — |
| Fighting | Normal, Ice, Rock, Dark, Steel | Poison, Flying, Psychic, Bug, Fairy | Ghost |
| Poison | Grass, Fairy | Poison, Ground, Rock, Ghost | Steel |
| Ground | Fire, Electric, Poison, Rock, Steel | Grass, Bug | Flying |
| Flying | Grass, Fighting, Bug | Electric, Rock, Steel | — |
| Psychic | Fighting, Poison | Psychic, Steel | Dark |
| Bug | Grass, Psychic, Dark | Fire, Fighting, Poison, Flying, Ghost, Steel, Fairy | — |
| Rock | Fire, Ice, Flying, Bug | Fighting, Ground, Steel | — |
| Ghost | Psychic, Ghost | Dark | Normal |
| Dragon | Dragon | Steel | Fairy |
| Dark | Psychic, Ghost | Fighting, Dark, Fairy | — |
| Steel | Ice, Rock, Fairy | Fire, Water, Electric, Steel | — |
| Fairy | Fighting, Dragon, Dark | Fire, Poison, Steel | — |

For a Pokémon with two current types, multiply the two ordinary modifiers. This can give 4×, 2×, 1×, 0.5×, 0.25×, or immunity. An immunity dominates the product unless a specific effect removes or bypasses it. A single type is applied once.

Use current defensive types. A Mega Evolution or a type-changing effect can alter the matchup before an attack. Type-specific exceptions such as Freeze-Dry, immunity-bypassing abilities, grounding, and move-specific effectiveness belong to the applicable entity definitions.

This table describes ordinary attack effectiveness. It is not a universal rule for whether a status move works. For example, type-based status immunity, powder immunity, and Prankster immunity are separate checks.
